# A Basic Chatbot

## Overview
A lightweight chatbot built using Hugging Face Inference API and Qwen2.5-1.5B-Instruct.

## Features
- Instruction-tuned LLM
- API-based inference
- Modular design

## Setup

1. Clone repo
2. Create virtual environment
3. Add HF_TOKEN as environment variable or replace it with hugging face token
4. Run app.py
